# ⏰ Digital Clock & Countdown Timer

A modern and responsive Digital Clock and Countdown Timer developed as part of my **Week 2 – CSS + Basic JavaScript Assignment** for the Skill Nexis Web Development Internship.

This project displays the current time in HH:MM:SS format and includes a countdown timer for New Year 2027.

## ✨ Features

- Live digital clock displaying hours, minutes, and seconds.
- Displays the current date and day.
- New Year 2027 countdown timer.
- Real-time updates every second.
- Attractive dark theme with neon styling.
- CSS hover animations.
- Responsive design for desktop and mobile devices.

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage.
- **CSS3** – Styling, animations, layouts, and responsiveness.
- **JavaScript** – Clock functionality and countdown calculations.

## 📚 JavaScript Concepts Used

| Concept | Purpose |
|---|---|
| `Date()` | Retrieves the current date and time |
| `getHours()` | Gets the current hour |
| `getMinutes()` | Gets the current minute |
| `getSeconds()` | Gets the current second |
| `setInterval()` | Updates the clock every second |
| `Math.floor()` | Calculates countdown values |
| `textContent` | Updates webpage content |
| `padStart()` | Adds leading zeros |
